# apps/api-rs

Optional Rust API with the same contract as `apps/api` (FastAPI). FastAPI stays the default.
Routes it does not serve are relayed to `FASTAPI_UPSTREAM` unchanged, so one URL serves both.

Parity is checked with `make parity` (`scripts/parity.sh`, `parity/run.py`): status, body and audit rows of each
request must match FastAPI for every key shape.
