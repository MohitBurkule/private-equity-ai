## Read before distributing: pymupdf is AGPL-3.0

- **pymupdf** (PyMuPDF) is dual licensed: GNU AGPL-3.0, or a commercial licence from Artifex. It is still a core dependency here, used by the parse engines (`apps/api/app/parse/`). Page images and quote highlights moved to pypdfium2 (`apps/api/app/page_image.py`).
- **What AGPL-3.0 means.** This repo is AGPL-3.0 itself, so using pymupdf is compatible. Anyone who runs a modified version over a network must offer that version's source to its users. Shipping closed-source software that links it would need the Artifex commercial licence or a replacement.
- **Permissive alternatives already in the codebase:**
  - `pypdf` (BSD-3-Clause), core dependency, used for text extraction.
  - `pdfplumber` (MIT), in the `pdf` extra, with line and table geometry.
  - `pypdfium2` (BSD-3-Clause for PDFium, Apache-2.0 for the bindings), in the `ocr` extra, for page rendering.
- **Still open:** the parse engines and router use pymupdf, so a closed-source release must either buy the Artifex licence or move those to pypdfium2 or pdfplumber. `page_image.py` is already on pypdfium2; its highlight boxes match pymupdf's within about 3 points on sample prose, table and wrapped-quote pages.
